TCP 帧头（每帧的前 4 字节）
Byte 0–3 uint32_t (Big-Endian) 后续载荷总长度 网络字节序，需 ntohl() 转换
载荷：自定义序列化的 CompressedImage 消息
+0 ~ +3 uint32_t seq 帧序列号（递增计数器）
+4 ~ +7 int32_t sec 时间戳 — 秒部分
+8 ~ +11 int32_t nsec 时间戳 — 纳秒部分
+12 ~ +15 uint32_t len frame_id 字符串长度
+16 ~ +N char[] frame_id 坐标系 ID 字符串（变长，无 null 终止）
+N+1 ~ +N+4 uint32_t len format 字符串长度
+N+5 ~ +M char[] format 图像编码格式名 通常为 "jpeg"
+M+1 ~ +M+4 uint32_t len JPEG 图像数据长度
+M+5 ~ end uint8_t[] data JPEG 压缩图像字节流 核心载荷
重点说明：帧头的 4 字节长度字段使用 Big-Endian（网络字节序）， 代码中通过 ntohl() 转换为主机字节序。
但载荷内部的所有整型字段（seq, sec, nsec, 各 len）直接使用 memcpy 读取， 隐含假设设备端与主机端字节序一致（均为 Little-Endian / x86/ARM）。
字符串采用「4 字节长度前缀 + 裸字节」格式，不包含 null 终止符。

receiveImages() 详细接收流程

1检查连接状态 isConnected()，未连接则 sleep 100ms 后重试
2readWithTimeout() 读取 4 字节 → 得到 data_size（帧头）
3ntohl(data_size) 将大端序转为主机小端序
4分配 vector<uint8_t>(data_size) 缓冲区
5readWithTimeout() 循环 recv 读取完整载荷（处理 TCP 分包）
6deserializeROSMessage() 按偏移解析各字段到 CompressedImageMsg
7cv::imdecode(data, IMREAD_COLOR) 将 JPEG → BGR cv::Mat
8按 height/2 分割：上半 = left 鱼眼，下半 = right 鱼眼
9cv_bridge 转换 → image_transport 发布到两个 ROS Topic

三线程并发模型

Main Thread（主线程）

  1. rclcpp::init() 初始化 ROS2
  2. 创建节点，声明参数 server_ip / server_port
  3. 构造 TCPImageClient（触发 initPublishers + startThreads）
  4. rclcpp::spin(node) 阻塞运行 ROS 事件循环
  5. Ctrl+C 退出时，析构函数 join 两个工作线程

Connect Thread（重连线程）

  1. 每秒检查一次连接状态
  2. 若断开，调用 connectWithTimeout()
  3. 创建 socket → 设为非阻塞模式
  4. 发起 connect()，用 select() 等待 3 秒
  5. 连接成功后恢复阻塞模式、更新 sockfd_
  6. 失败则 sleep 1s 后继续循环

Receive Thread（接收线程）

  1. 等待连接就绪
  2. select() + recv() 读取 4 字节帧头
  3. ntohl() 转换长度，分配缓冲区
  4. 循环 recv 直到读满全部载荷
  5. deserializeROSMessage() 解析字段
  6. cv::imdecode() JPEG 解码为 BGR
  7. 分割 → cv_bridge → 发布两路图像
  8. 异常时断开连接，由重连线程恢复

编码类型与数据格式一览

阶段编码/格式说明
设备端压缩 JPEG 设备将原始双鱼眼拼接图 JPEG 压缩后发送，大幅降低 TCP 传输带宽
帧头长度字段 Big-Endian (网络序) TCP 帧的前 4 字节使用网络字节序，代码用 ntohl() 转换
载荷内整型字段 Little-Endian (隐含) seq/sec/nsec/内部 len 直接 memcpy，假设设备端也是小端序
字符串编码 Length-Prefixed frame_id / format 均为「4 字节长度 + 裸字符串」，非 null 终止
JPEG 解码后 BGR8 (cv::Mat) OpenCV imdecode(IMREAD_COLOR) 默认输出 BGR 三通道 8bit
ROS Topic 发布 sensor_msgs/Image BGR8 cv_bridge 设置 encoding = BGR8，以原始像素格式发布到 ROS Topic

连接安全与异常处理机制

非阻塞连接：使用 fcntl(O_NONBLOCK) 将 socket 设为非阻塞， 配合 select() 实现 3 秒连接超时，避免线程长时间挂起。

线程安全：sock_mutex_ (std::mutex) 保护 sockfd_ 的读写； running_ 为 std::atomic<bool>， 确保跨线程信号传递的可见性。

完整读取保证：readWithTimeout() 内部循环调用 recv()， 累积 bytes_received 直到读满所需字节数，正确处理 TCP 分包/粘包问题。

自动重连：接收线程在任何 recv 失败或解码异常时调用 disconnect()， 重连线程每秒检测到断开后自动发起重连，无需人工干预。

超时分级：帧头读取超时 1 秒（检测连接断开），载荷数据读取超时 3 秒（容忍网络波动）。
